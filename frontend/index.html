Identifícate para entrar al panel

El identificador que devolvió la API al registrar la cuenta. Se comprueba contra la base de datos antes de entrar.

Verificación de contraseña pendiente de backend

La API actual solo expone POST /api/usuarios: no existe ningún endpoint de inicio de sesión, por lo que el frontend no puede comprobar correo y contraseña. Este acceso valida contra MySQL que el usuario exista y aísla el panel tras el flujo de entrada. Pedir aquí una contraseña que nadie verifica daría una falsa sensación de seguridad, así que no se solicita.

Datos de la nueva cuenta

Mínimo 8 caracteres. Se envía a la API, que la cifra con bcrypt antes de guardarla; el navegador no la almacena en ningún momento.

Los importes se muestran en pesos colombianos (COP) y se calculan íntegramente en el backend.
