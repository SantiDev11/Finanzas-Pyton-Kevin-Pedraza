Alcance actual del acceso

La API todavía no expone un endpoint de verificación de credenciales: el único endpoint de usuarios es POST /api/usuarios (registro). El acceso comprueba contra MySQL que el usuario exista y guarda la sesión en esta pestaña, pero la contraseña no se verifica en el backend. No hay JWT ni tokens de sesión.

Las contraseñas sí se cifran con bcrypt al registrarse y nunca se almacenan en el navegador. La verificación real queda pendiente de un endpoint de inicio de sesión en el backend.
